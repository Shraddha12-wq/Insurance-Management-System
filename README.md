
# Insurance Management System

## Project Overview
The Insurance Management System is a web-based application developed using ASP.NET, C#, and SQL Server. It helps users explore insurance services, register, submit enquiries, and interact with the insurance management system.

## Technologies Used
- ASP.NET Web Forms
- C#
- Microsoft SQL Server
- HTML
- CSS
- JavaScript
- Bootstrap

## Features

### User Features
- User Registration
- User Login
- View Insurance Services
- Life Insurance
- Health Insurance
- Car Insurance
- Home Insurance
- Mobile Insurance
- Submit Enquiries
- Submit Feedback
- Change Password

### Admin / Management
- Manage insurance-related information
- Handle user enquiries
- Manage application data

*Note: Admin features should be adjusted according to the actual implemented functionality.*

## Database
The project uses Microsoft SQL Server database files.

## Installation and Setup
1. Clone this repository.
2. Open the project in Microsoft Visual Studio.
3. Configure the SQL Server database connection.
4. Attach or restore the required database locally.
5. Run the project using IIS Express or IIS.
